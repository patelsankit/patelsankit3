# Sankit Parasiya — Portfolio

Personal portfolio built with Next.js (App Router), Tailwind CSS v4 and Motion.

## Develop

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```

## Editing content

All copy, links, jobs, skills and projects live in `src/data/profile.ts`.

- Project screenshots: `public/projects/*.webp` (16:10 works best)
- Company logos: `public/logos/` (jobs without a `logo` show a monogram)
- Skill icons: `public/skills/*.svg` (from Simple Icons, tinted via CSS mask)
- Résumé PDF: `public/sankit-parasiya-resume.pdf`
- `profile.url` sets the canonical URL, sitemap and social-card base. Update it if you deploy to a new domain.
